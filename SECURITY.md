# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security** tab to submit a private vulnerability report through
GitHub Private Vulnerability Reporting.

Include a concise description, reproduction steps, the affected version, and
the expected impact. Remove API tokens, account IDs, public IP addresses, and
other sensitive infrastructure details from all reports.

If private vulnerability reporting is not enabled for the repository, ask the
maintainer in a public issue to enable it without disclosing any vulnerability
details.
